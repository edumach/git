
# Git: cvičení (rostliny)

> max 30 minut

---

Vytvořte složku `prijmeni-rostliny` a v něm založte git repozitář. Další činnosti provádějte v této složce.

---

**1. Vytvoření souboru:**

Vytvořte soubor `stromy.txt` s tímto obsahem:

```
Dub
Buk
Javor
```

⬆️ Vytvořte první commit s komentářem: "založení projektu"

---

**2. README:**

Vytvořte soubor `README.md` s tímto obsahem:

```
# Projekt Git – rostliny
Tento projekt slouží k procvičení práce s commity a správou souborů.
---
```

⬆️ Vytvořte commit s komentářem: "přidání README"

---

**3. Další soubor:**

Vytvořte soubor `kvetiny.txt` s následujícím obsahem:

```
Růže
Slunečnice
Tulipán
```

⬆️ Vytvořte commit s komentářem: "přidání květin"

---

**4. Souhrnný soubor:**

Vytvořte soubor `rostliny.txt` a přidejte tento obsah:

```
Seznam rostlin
--------------
- stromy
- květiny
```

⬆️ Vytvořte commit s komentářem: "vytvoření souhrnného seznamu"

**5. Soubor `.gitignore`:**

1. Vytvořte soubor `poznamky.txt` s libovolným obsahem (např. "Toto je můj pracovní soubor.").
2. Vytvořte soubor `.gitignore` a zapište do něj:

```
poznamky.txt
```

⬆️ Vytvořte commit s komentářem: ".gitignore přidán"

Ověřte pomocí `git status`, že soubor `poznamky.txt` se už v repozitáři neukazuje jako změněný/nesledovaný.

---

**6. Úprava README:**

Do souboru `README.md` přidejte na konec tento text:

```
Autor: Jméno Příjmení
```

⬆️ Vytvořte commit s komentářem: "doplnění README"

---

Odevzdejte podle pokynů vyučujícího.
