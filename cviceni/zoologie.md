
# Git/GitLab: cvičení (zoologie)

> max 35 minut

---

Vytvořte adresář `zoologie`. V něm založte git repozitář. Další činnosti provádějte v tomto adresáři.


---

**1. Vytvoření souboru**

Vytvořte soubor `zvirata.txt` s tímto obsahem:

```
Pes
Kočka
Kůň
```

⬆️ Vytvořte první commit s komentářem: "počáteční data"

---

**2. README:**

Vytvořte soubor `README.md` s tímto obsahem:

```
# Projekt Git – zoologie
Tento projekt slouží k procvičení práce s commity a správou souborů.
---
```

⬆️ Commit: "přidán README"

---

**3. Další soubor:**

Vytvořte soubor `ptaci.txt` s obsahem:

```
Sova
Vrána
Kalous
```

⬆️ Commit: "přidání ptáků"

---

**4. Souhrnný soubor:**

Vytvořte soubor `zoologie.txt` a přidejte:

```
Přehled skupin
--------------
- savci
- ptáci
```

⬆️ Commit: "souhrnný přehled"

---

**5. Soubor `.gitignore`:**

1. Vytvořte soubor `pracovni.txt` s libovolným textem (např. „Neukládat do Gitu“).
2. Vytvořte soubor `.gitignore` a zapište do něj:

```
pracovni.txt
```

⬆️ Commit: ".gitignore vytvořen"

Ověřte pomocí `git status`, že se soubor `pracovni.txt` již neobjevuje mezi změnami.

---

**6. Úprava README:**

Do souboru `README.md` přidejte na konec:

```
Autor: Jméno Příjmení
```

⬆️ Commit: "doplněn autor"

---

**7. Odeslání repozitáře na GitLab:**

Repozitář napojte na váš školní GitLab a odešlete jej.

Jeho viditelnost nastavte na **Internal**.
